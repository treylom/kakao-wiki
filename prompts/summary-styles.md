# 요약 스타일 프리셋 (summary styles)

`summarize.py` 가 이 파일을 읽어 스타일별 프롬프트를 만든다. 각 스타일 = `## <id>` 헤더 +
바로 아래 코드블록(```)의 프롬프트 본문. `{context}` 자리표시자는 수집 데이터 요약(방·기간·
메시지 수·주요 발화자)으로 치환된다. 새 스타일을 추가하려면 같은 형식으로 한 절을 더 쓰면 된다.

> 환경 감지: `/prompt` 스킬이 있는 환경이면 `summarize.py` 가 그 스킬 사용을 안내하고,
> 없으면 아래 프리셋 중 선택한 스타일의 프롬프트를 그대로 출력한다(요약 LLM에 전달).

> **모든 스타일 공통 규율** — 아래 각 프리셋에 이미 반영돼 있다. 새 스타일을 추가할 때도 지킬 것:
> - **해석·편집자 말투 금지.** "핵심은 ~", "짚어볼 점", "오늘의 한 줄" 처럼 요약자가 의미를
>   덧입히는 문장을 *만들어내지* 말 것. 대화에 있었던 것만 옮긴다(지나친 요약 지양). 이건 취향이
>   아니라 요약 도구의 일반 덕목이다 — 도구가 단정 말투를 얹기 시작하면 사용자가 원문과 해석을
>   구분할 수 없다.
> - **인용은 원문 그대로.** 따옴표 안 문장은 대화에 실제로 있던 문자열이어야 한다. 바꿔 쓰지 말 것
>   (사후 `scripts/gates/citation_gate.py` 로 verbatim 검증 가능).
> - **길이 예산 준수.** 각 스타일의 분량 상한을 지킨다 — 발신 채널의 무고지 절단을 피하기 위함이고,
>   발송 시점의 하드 상한은 `scripts/gates/length_gate.py` 가 관문에서 다시 잡는다.

## brief
```
아래 카카오톡 대화({context})를 한국어로 **3줄 이내** 핵심만 요약해줘.
- 군더더기·인사말 빼고 결정/이슈/숫자 중심.
- 과장·평가 없이 사실만. 인용은 넣지 말 것.
- "핵심은~"·"짚어볼 점" 같은 편집자 말투 금지 — 있었던 것만.
```

## detailed
```
아래 카카오톡 대화({context})를 한국어로 **상세 요약**해줘. 분량은 주제별로 묶어 10~15줄 내외.
- 주제별로 묶어 흐름이 보이게(무슨 일이 있었나 → 무엇을 정했나).
- 중요한 발언은 주제마다 1~2개만 짧게 인용(따옴표), **인용은 원문 그대로**(바꿔쓰기 ❌).
- 마지막에 후속 액션이 있으면 항목으로 정리.
- 요약자가 의미를 덧입히는 "핵심은~"·"짚어볼 점"·"오늘의 한 줄" 류 문장은 만들지 말 것.
```

## bullets
```
아래 카카오톡 대화({context})를 한국어 **불릿 목록**으로 요약해줘.
- 한 줄에 한 포인트, 5~8개.
- 각 불릿은 명사형/간결체로. 이모지·마크다운 강조 없이 평문.
- 대화에 있던 사실만. 편집자 해석("핵심은~"·"짚어볼 점")은 넣지 말 것.
```

## formal
```
아래 카카오톡 대화({context})를 한국어 **보고체(존댓말)**로 요약해줘. 핵심→결정사항→후속 각 절 간결히(전체 10줄 내외).
- "~했습니다 / ~로 결정되었습니다" 톤, 윗사람 보고 형식.
- 핵심 → 결정사항 → 후속 순서. 추측 없이 대화에 있는 내용만.
- 인용을 넣을 경우 원문 그대로. 요약자의 해석·평가 말투("짚어볼 점" 류)는 붙이지 말 것.
```

## casual
```
아래 카카오톡 대화({context})를 **편한 반말 톤**으로 짧게 풀어줘.
- 친구한테 "오늘 단톡방에서 이런 얘기 나왔어" 하듯이.
- 핵심만, 2~4문장. 과장 없이.
- 대화에 있던 것만 — "핵심은~"·"오늘의 한 줄" 같이 의미 덧입히는 말은 빼고.
```
